# Bikeshare Data Analysis

## Project Overview
	This project was completed as part of the Udacity Programming for Data Science / Git & GitHub coursework.
	The objective is to analyze bikeshare usage data from multiple cities and provide interactive statistics through a Python 	commandline application.

	The program allows users to explore data by selecting a city, month, and day of the week, then generates useful insights about 	travel patterns and user demographics.
---
## Features
	The application provides:
		- Popular travel times
		- Popular stations and routes
		- Trip duration statistics
		- User type statistics
		- Gender statistics (when available)
		- Birth year statistics (when available)
		- Ability to view raw data records
